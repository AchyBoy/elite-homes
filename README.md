# Elite Homes — concept site

A spec/demo website built to pitch Elite Homes. Single self-contained `index.html`,
no build step, no backend.

All content is placeholder: names, dates, figures, testimonial and photos are
samples, not real company information. The page is `noindex` and is meant to be
shared by direct link only.

Live: https://achyboy.github.io/elite-homes/

## Local preview
```
python3 -m http.server 8644 --directory .
```
